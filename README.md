# MentorOS

MentorOS is an AI-powered personal mentor, learning tracker, career dashboard, and living portfolio.

## Vision

MentorOS helps users:

- Set and manage long-term goals
- Create structured learning plans
- Generate daily tasks
- Track progress
- Evaluate knowledge through AI-generated tests
- Adapt learning plans based on performance
- Track career activity
- Connect developer and social profiles
- Maintain a living technical portfolio
